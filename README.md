# TechNova IT — เว็บไซต์ร้านขายอุปกรณ์ IT (เวอร์ชันเต็ม)

**แบรนด์:** TechNova IT
**สินค้าที่ขาย:** ครบทุกเทคโนโลยี เพื่อทุกไลฟ์สไตล์ดิจิทัล
**สโลแกน:** ไอทีคุณภาพ ราคาที่ใช่ (Smart Tech, Smart Choice)
**จัดทำโดย:** รหัสนักศึกษา 66040233110 นายยศวริศ อาจนนท์ลา

เว็บไซต์ร้านขายอุปกรณ์ IT แบบเต็มระบบ คล้าย Shopee/Lazada ย่อส่วน — มีระบบสมาชิก,
อัปโหลดรูปสินค้าได้หลายรูป, รีวิว/ให้ดาว, สินค้าโปรด, คูปองส่วนลด, สมุดที่อยู่หลายที่,

## 🧰 ภาษา/เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี | เหตุผลที่เลือกใช้ |
|---|---|---|
| Backend | **Node.js + Express** (JavaScript) | เขียนง่าย มีตัวอย่างเยอะ เหมาะกับงานส่งครู |
| ฐานข้อมูล | **SQLite ผ่าน sql.js** | sql.js คือ SQLite แบบ WebAssembly ไม่ต้องคอมไพล์โปรแกรมเสริมใดๆ ติดตั้งชัวร์ทุกเครื่อง แม้เครื่องไม่เคยลง build tools |
| อัปโหลดไฟล์ | **multer** | รับไฟล์รูปจากฟอร์ม แล้วเซฟลงโฟลเดอร์ `public/uploads/` |
| ส่งอีเมล | **nodemailer + Gmail SMTP** | ส่งอีเมลลิงก์รีเซ็ตรหัสผ่านจริง |
| รหัสผ่าน | **bcryptjs** | เข้ารหัสรหัสผ่านก่อนเก็บ ไม่เก็บ plain text |
| Session | **express-session** | จำสถานะ login ของแต่ละคน |
| Frontend | **HTML + CSS + JavaScript ธรรมดา** (ไม่มี framework) | ไม่ต้องมีขั้นตอน build ใดๆ เปิดแล้วรันได้ทันที แก้โค้ดง่าย |

## 🚀 วิธีติดตั้งและรัน

### 1. ติดตั้ง Node.js
ถ้ายังไม่มีในเครื่อง โหลดได้ที่ [nodejs.org](https://nodejs.org) (เวอร์ชัน 18 ขึ้นไป)

### 2. ติดตั้งไลบรารีที่ใช้
เปิด Terminal / Command Prompt แล้ว `cd` เข้าโฟลเดอร์นี้ แล้วรัน:
```
npm install
```

### 3. ตั้งค่าไฟล์ .env (สำหรับส่งอีเมลลืมรหัสผ่านจริง)
โปรเจกต์นี้มีไฟล์ `.env` มาให้แล้ว (มีข้อมูลตัวอย่างที่ยังใช้ไม่ได้จริง)
ถ้าอยากให้ระบบ "ลืมรหัสผ่าน" ส่งอีเมลจริง ให้ทำตามนี้:

1. เข้า [myaccount.google.com/security](https://myaccount.google.com/security)
2. เปิด **การยืนยันแบบ 2 ขั้นตอน (2-Step Verification)** ก่อน (ถ้ายังไม่เปิด)
3. ไปที่ [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords)
4. สร้าง App Password ใหม่ ตั้งชื่ออะไรก็ได้ เช่น `it-store`
5. Google จะให้รหัส 16 หลัก เอามาใส่ในไฟล์ `.env`:
   ```
   GMAIL_USER=youremail@gmail.com
   GMAIL_APP_PASSWORD=รหัส16หลักที่ได้มา
   ```

**ถ้าไม่อยากตั้งค่าอีเมล** ก็รันได้ปกติเลย — ระบบจะสลับไปโหมดจำลองอัตโนมัติ
(โชว์ลิงก์รีเซ็ตบนหน้าจอแทนการส่งอีเมลจริง) ใช้ทดสอบ flow ได้เหมือนกัน

### 4. รันเซิร์ฟเวอร์
```
npm start
```
แล้วเปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

ฐานข้อมูล SQLite (`db/store.sqlite`) จะถูกสร้างขึ้นเองอัตโนมัติพร้อมข้อมูลตัวอย่างในการรันครั้งแรก

## 📁 โครงสร้างโปรเจกต์ (ไฟล์ไหนทำหน้าที่อะไร)

```
it-store/
├── server.js                 ← จุดเริ่มต้นของแอป รวมทุก route เข้าด้วยกัน
├── .env                       ← ค่าลับ (Gmail, session secret) — ห้ามแชร์ไฟล์นี้ให้คนอื่น
├── .env.example               ← ตัวอย่างไฟล์ .env พร้อมคำอธิบายวิธีตั้งค่า
│
├── db/
│   └── init.js                ← สร้างตาราง SQL ทั้งหมด + ข้อมูลตัวอย่าง (แก้ schema ที่นี่)

├── utils/

├── routes/                     ← แต่ละไฟล์ = 1 กลุ่มฟีเจอร์ (ทุกไฟล์คอมเมนต์ไว้ละเอียด)
│   ├── middleware.js            ← ตัวเช็คสิทธิ์ (ต้อง login / ต้องเป็นแอดมิน / เช็คบัญชีถูกแบน)
│   ├── auth.js                  ← สมัคร/login/logout/ลืมรหัสผ่าน/แก้โปรไฟล์/เปลี่ยนรหัสผ่าน
│   ├── products.js               ← ดู/เพิ่ม/แก้ไข/ลบสินค้า + อัปโหลด-ลบรูปสินค้า
│   ├── categories.js             ← จัดการหมวดหมู่สินค้า
│   ├── addresses.js              ← สมุดที่อยู่จัดส่งของลูกค้า (หลายที่อยู่ได้)
│   ├── orders.js                 ← สั่งซื้อ/ประวัติคำสั่งซื้อ/เปลี่ยนสถานะ (แอดมิน)
│   ├── coupons.js                ← คูปองส่วนลด (สร้าง/แก้ไข/ตรวจสอบโค้ด)
│   ├── reviews.js                ← รีวิว + ให้ดาวสินค้า
│   ├── wishlist.js               ← สินค้าโปรด
│   └── admin.js                  ← สถิติภาพรวมร้าน + จัดการผู้ใช้ (สิทธิ์/แบน)

└── public/                     ← หน้าเว็บ (frontend ธรรมดา ไม่ต้อง build)
    ├── index.html                ← โครง HTML หลัก (มีแค่ไฟล์เดียว เพราะเป็น Single Page App)
    ├── style.css                  ← สไตล์ทั้งหมด แบ่งเป็น section มีคอมเมนต์กำกับ

    ├── images/logo.png             ← โลโก้ร้าน
    └── uploads/                   ← โฟลเดอร์เก็บรูปที่อัปโหลดจริง (สร้างอัตโนมัติ)
```

### เจาะลึกไฟล์ `public/app.js` (เพราะเป็นไฟล์ที่ใหญ่ที่สุด)
ไฟล์นี้แบ่งเป็น 5 ส่วน (มีคอมเมนต์หัวข้อใหญ่กำกับไว้ในไฟล์จริงด้วย):
1. **Helper functions** — ฟังก์ชันเรียก API, แจ้งเตือน, จัดรูปแบบเงิน/ดาว/สถานะ
2. **Navbar** — เมนูด้านบนที่เปลี่ยนตามสถานะ login
3. **Views ฝั่งลูกค้า** — หน้าแรก, สินค้า, ตะกร้า, checkout, login, โปรไฟล์, ที่อยู่, สินค้าโปรด, ประวัติคำสั่งซื้อ
4. **Views ฝั่งแอดมิน** — แดชบอร์ด, จัดการสินค้า/หมวดหมู่/ออเดอร์/คูปอง/ผู้ใช้
5. **Router** — จับคู่ URL (เช่น `#/products`) กับหน้าที่ต้องแสดง

ระบบ routing เป็นแบบ **hash routing** (`#/products`, `#/product/3`, `#/admin/orders` ฯลฯ)
ไม่ใช้ library ใดๆ เขียนเองแบบง่ายๆ ในฟังก์ชัน `router()` ท้ายไฟล์

## ✏️ วิธีต่อยอด/แก้ไข (สำหรับแก้เอง)

### อยากเพิ่มหน้าใหม่
1. เขียนฟังก์ชัน `viewXxx()` ใหม่ใน `public/app.js` (ดูฟังก์ชันที่มีอยู่เป็นตัวอย่าง)
2. เพิ่มเงื่อนไขใน `router()` (ท้ายไฟล์) ให้ path ใหม่ชี้มาที่ฟังก์ชันนั้น
3. ถ้าต้องใช้ข้อมูลจากฐานข้อมูล ต้องสร้าง API endpoint คู่กันใน `routes/` ด้วย

### อยากแก้ไขหน้าเดิม
หาฟังก์ชันชื่อ `viewXxx()` ที่ตรงกับหน้านั้นใน `public/app.js` (เช่น `viewHome()`, `viewCart()`)

### อยากลบหน้า
ลบฟังก์ชัน `viewXxx()` และเงื่อนไขที่เกี่ยวข้องใน `router()` ออก

### อยากเพิ่มคอลัมน์/ตารางใหม่ในฐานข้อมูล
แก้ไข `db/init.js` ส่วน `createSchemaAndSeed()` แล้วลบไฟล์ `db/store.sqlite`
ทิ้ง (ฐานข้อมูลจะถูกสร้างใหม่พร้อม schema ล่าสุดตอนรันครั้งถัดไป — **ข้อมูลเดิมจะหายหมด**
ถ้าอยากเก็บข้อมูลเดิมต้องเขียน SQL คำสั่ง `ALTER TABLE` เพิ่มเองแทนการลบไฟล์)

### อยากเพิ่ม API endpoint ใหม่
สร้างไฟล์ใหม่ในโฟลเดอร์ `routes/` (หรือเพิ่มใน route เดิมที่เกี่ยวข้อง) แล้วไป `require()`
+ `app.use()` เพิ่มใน `server.js`

- ลิงก์ลืมรหัสผ่านหมดอายุใน 1 ชั่วโมง และใช้ได้ครั้งเดียว
- จำกัดชนิดไฟล์ที่อัปโหลดได้เฉพาะรูปภาพ (.jpg .jpeg .png .webp .gif) และจำกัดขนาดไฟล์
